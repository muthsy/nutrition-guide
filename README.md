# الدليل الغذائي

دليل غذائي تفاعلي بالعربية يعمل كتطبيق على الهاتف (PWA):

- القيم الغذائية لـ 90 صنفًا مع المقادير المنزلية (ملعقة، كوب، حبة) والفوائد والأضرار
- 136 وجبة عربية مع طريقة التحضير ووزن الطبق، بثلاث ميزانيات
- نظام غذائي مخصص حسب العمر والطول والوزن، مع إمكانية الجمع بين أكثر من هدف
- تصدير بطاقات الأصناف والوجبات والبرنامج صورةً أو PDF
- يعمل دون إنترنت بعد أول فتح

## النشر على GitHub Pages

Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** / **(root)** ← Save.
بعد دقيقة أو اثنتين يصبح الرابط: `https://<اسم-الحساب>.github.io/<اسم-المستودع>/`

## التحديث

عند استبدال `index.html` غيّر قيمة `CACHE` في `sw.js` (مثلًا `nutri-v5`) حتى يصل التحديث لمن ثبّت التطبيق.

> المحتوى للتثقيف العام ولا يغني عن استشارة الطبيب أو أخصائي التغذية.
> الرسوم التوضيحية من Microsoft Fluent Emoji (رخصة MIT)، والخطوط Cairo وTajawal وAmiri Quran (رخصة SIL OFL).
